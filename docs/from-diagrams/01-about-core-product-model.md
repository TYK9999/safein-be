# About — SafeIn5 Core Product Model

Source: product overview / “About” deck.

## Core product model — what it is

- **Core principle:** “Safer by Sharing”
- SafeIn5 is **not** a reporting system — it is a behavioural intelligence platform that turns human awareness into shared safety intelligence
- Built around two connected systems: **PULSE** (worker behavioural loop) + **SIGNAL** (intelligence loop)
- **PULSE** creates the moment of awareness → **SIGNAL** captures/routes the learning → system feeds intelligence back into the next **PULSE** moment

## Key definitions (glossary)

| Term | Definition |
| --- | --- |
| Behavioural Signal | Digital record of a worker's observation that could help others stay safe (core data unit) |
| Behavioural Signal Draft | Incomplete signal captured during Capture phase, before classification |
| PULSE | 5-step worker method: Pause, Uncover, Learn, Steer, Echo |
| SIGNAL | Intelligence loop: Sense, Identify, Gather, Navigate, Alert, Loop |
| Take 5 | Pre-task behavioural pause/checklist (the “P” of PULSE) |
| Learn 5 | Short-form micro-learning delivered via QR / workflow / trends |
| Classification | Categorizing a signal in &lt;10 seconds |
| Context | Site / Asset / Task / Risk Type auto-attached via QR scan |

## What a behavioural signal represents

“Something someone notices, learns, or shares that could help others stay safe”

- **Good Practice** — something working well others can learn from
- **Something to be aware of** — emerging condition / behaviour / context that could become risk
- **Needs attention now** — risk requiring prompt awareness / escalation / action

## System objects

- Behaviour Signal Draft (fast capture, pre-classification)
- Behaviour Signal (finalised, post-classification + context)
- PULSE Session (pre-task pause that may generate a signal)
- Learn 5 Item (learning content linked to context / trends / QR)

**Key fields:** text (optional), media (optional photo/video), classification, context (QR / site / asset / task / risk type), timestamp, routing status

## The two loops

### PULSE (Worker Behavioural Loop)

Supports safer decisions in under 5 minutes:

1. **Pause** — stop, reset awareness
2. **Uncover** — identify what's different / what could go wrong
3. **Learn** — recall fundamentals, safest option
4. **Steer** — take safest action, one deliberate improvement
5. **Echo** — share as a SIGNAL

### SIGNAL (Intelligence Loop — Platform System)

1. **Sense** — receive signals (frontline, community, QR, corporate)
2. **Identify** — recognise risk patterns / anomalies
3. **Gather** — aggregate across users / sites / assets / teams / time
4. **Navigate** — route to right people / dashboards / workflows
5. **Alert** — trigger nudges / warnings / escalations
6. **Loop** — feed intelligence back into next PULSE moment

## Users / layers (two ecosystems)

### Community layer

- Capture signals (photo / video / text), optional geolocation
- Simple classification, feed display, search / filter, PULSE prompts, Learn 5 content

### Corporate layer

- Org / site setup, geolocation, internal feeds, workflow management, QR-linked content (PULSE / rescue plans), dashboard

### System-wide

- Authentication (user + optional anonymity), role-based access, consent / visibility control
