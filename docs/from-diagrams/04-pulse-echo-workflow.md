# Every PULSE create an ECHO!

Source: PULSE / ECHO process flowchart (confined-space / frontline worker journey).

## Observation vs work-task pulse

- Observation Pulse
- Work Task Pulse

## Initial state

1. **User created in SafeIn5 System** (database)
2. Assuming **logged-in state**
3. Actor: **Frontline Worker**
4. Offline prerequisite: **Assuming all permits and paperwork in place** (offline activity)

## PULSE — Before entering confined space

| Step | Action | Notes |
| --- | --- | --- |
| 1 | **PAUSE** | Self-triggered; can also be triggered by geo-location |
| 2 | **Scan QR (Confined Space)** | Context loads (Space, Task, Permits). **Job starts** here |
| 3 | **Take 5 (Checklist)** | Uncover — “What's different today?” |
| 4 | **Learn 5 + Rescue Plan (Flash Cards)** | Toolbox Talks. Note: **No Learning for community** |

### Decision: Checklist OK?

- **No** → enter ECHO (capture media)
- **Yes** → Decision: **Shift needed?**
  - **No** → **No changes needed**
  - **Yes** → **Share with others** → enter ECHO

## ECHO

1. **Take Picture / Video + Voice Note** (max 30 seconds)
2. Decision: **How does it look?**

### Classification (user controlled)

| Classification | Colour | Guidance |
| --- | --- | --- |
| Good Practice | Green | Everything OK — capture as good practice |
| Be Aware | Orange | 1 item missing — Be aware |
| Needs Attention now | Red | More than 1 — Needs attention |

- **Needs Attention now** may also trigger offline activity: **Radio Supervisor / Site In-charge**

3. All paths → **Confirm and Share (Your Share)**
   - Work task
   - Observation (only in case of a shift)
4. **Job closed + Geo location shared**
5. Exit messaging (depending on classification): thank-you / someone will look into this

## Flow summary

```
Login → Permits ready (offline)
  → Pause (self / geo)
  → Scan QR (job starts; context loads)
  → Take 5 checklist (+ optional Learn 5 / Rescue Plan)
  → Checklist OK?
       No  → ECHO capture
       Yes → Shift needed?
              No  → No changes needed
              Yes → Share with others → ECHO capture
  → Classify (Good Practice / Be Aware / Needs Attention)
  → Confirm & Share → Job closed + geo shared
```
