# Take 5 — confined space entry

One list, **highest priority first**. Independent of any named site or space. A client attaches this list to whatever confined-space tasks they choose.

Sources: IMSF 100, Tarmac Special Permit — Confined Space, A3 PTW 2020, Toolbox Talk — Confined Spaces. Location, plant, tank and contact details removed.

Priority order: **do not enter → atmosphere → isolations → permit → rescue → specified risks → competence → conditions and PPE → remaining controls.**

If any check cannot be complied with: **stop immediately and contact your supervisor** (Tarmac Special Permit, Section 2).

| Priority | Check |
|---|---|
| 1 | Can the need to enter the confined space be avoided (remote controls, video camera, inspection hatches)? |
| 2 | Can the specified risk or enclosed nature be removed so a confined-space permit is not required? |
| 3 | Has the atmosphere been verified as safe prior to entry and recorded on the permit? |
| 4 | Have personal air monitoring devices with a current calibration certificate been provided for everyone who will enter? |
| 5 | Have monitors — and ELSA if required — been checked prior to entry? |
| 6 | Is gas monitoring continuous during entry? |
| 7 | Are all isolations checked before work commences as part of the permit? |
| 8 | Can pipework be isolated to prevent gas, fume or vapour entering? |
| 9 | Are inlets and outlets isolated and disconnected? |
| 10 | Can mechanical and electrical isolation be completed so nothing can operate or discharge into the space? |
| 11 | Have vessels been de-pressurised? |
| 12 | Has the confined space been emptied of contents, including residues, where possible? |
| 13 | Have hazardous / combustible materials been removed? |
| 14 | Has a confined space permit been raised, including these control measures? **Mandatory.** |
| 15 | Has everyone entering signed the permit, and do they understand its conditions (who is allowed in, PPE, how long it lasts, special instructions)? |
| 16 | Has an emergency / rescue plan been prepared and communicated for this entry? |
| 17 | Is there a suitable method of raising the alarm? |
| 18 | Has rescue and resuscitation equipment been identified and provided? |
| 19 | Is access equipment available — tripod, full body harness and winch? |
| 20 | Is a safety harness / lifeline required, and is it in use? |
| 21 | Is a person controlling access / egress at the entry, in position? |
| 22 | Is there adequate communication between persons inside and those outside — at least two methods? |
| 23 | Has adequate access been provided for safe entry and egress? |
| 24 | If breathing apparatus is required, is the opening large enough for BA (minimum 575 mm square)? |
| 25 | Is breathing apparatus required? Are those using it competent? |
| 26 | Is an emergency escape set required? Are those who may have to use it competent? |
| 27 | Risk of gas, fume, vapour or lack of oxygen — are the specified controls in place? |
| 28 | Risk of fire or explosion — are the specified controls in place? |
| 29 | Risk of a free flowing solid — are the specified controls in place? |
| 30 | Risk of an increase in liquid level — are the specified controls in place? |
| 31 | Have all persons who will manage or enter received specific confined-space training, demonstrated competency, and been authorised? |
| 32 | Are they medically fit (and of suitable build and fitness if the layout or task constrains this)? |
| 33 | Is sufficient ventilation available (natural or forced)? Do not force oxygen in — that can create an explosive atmosphere. |
| 34 | If a flammable or explosive atmosphere is possible, are ignition sources removed or controlled? |
| 35 | Has a specific risk assessment been completed for this work? |
| 36 | Has the risk assessment considered abnormal, temporary and work-created risks (e.g. burning, welding, static)? |
| 37 | Has a safe system of work been prepared, and is it relevant to the planned activity? |
| 38 | Does the safe system of work specify the measures to be taken in an emergency? |
| 39 | Has the correct PPE been specified for this activity, including rescue harnesses / lifelines? |
| 40 | Has suitable PPE been provided for everyone entering, and is it being used? |
| 41 | Is PPE in good condition and appropriate for the conditions? |
| 42 | Is burning or welding to be carried out? |
| 43 | If appropriate, have non-sparking tools been specified and provided? |
| 44 | Is there a possibility of static discharge? |
| 45 | Are precautions in place against electric shock in metal tanks (low voltage / RCD)? |
| 46 | Risk of increased body temperature — are the specified controls in place? |
| 47 | Is temperature acceptable, and can it be monitored so operatives do not overheat? |
| 48 | Is lighting adequate? |
| 49 | Are walkways and platforms to the opening safe to use? |
| 50 | Are warning signs displayed (confined space, and that people are inside)? |
| 51 | Is the opening secured (barrier, guard or gate) to deter unauthorised access? |
| 52 | Has the inside been cleaned where required? |
| 53 | Are first aid provisions adequate? |
| 54 | Are persons responsible for emergency response trained and practised? |
| 55 | Do they understand the precautions to be taken? |
| 56 | If the permit is still in force, has it been reviewed today and have any changes been documented? |
| 57 | If the task, the working environment or the method of work changes so the HIRA no longer covers it, has work stopped? |

Atmosphere results sit on the permit, not as extra Take 5 questions: O₂ >20.5% and <21% · CO <25 ppm · H₂S <5 ppm · CH₄ <1% or <20 LEL · O₃ <0.1 ppt · CO₂ <5000 ppm (A3 PTW 2020).
