## Slide 3: OurUnderstanding

- The Big Picture
- SafeIn5 helps frontline workers / technicians make safer decisions by turning everyday observations into shared safety awareness before incidents occur.
- The product is built around the PULSE and SIGNAL behavioural systems
- TALENTICA SOFTWARE
- SFAEIN5 - PROPOSAL
- SIGNAL
- Sense, Identify, Gather, Navigate, Alert, Loop — a shared safety intelligence loop that captures frontline observations, surfaces patterns and risks, and feeds learning back into future safety decisions.
- PULSE
- Pause, Uncover, Learn, Shift, Echo — a frontline behavioural loop that helps workers identify risks early, make safer decisions, and share learnings before work proceeds.

## Slide 17: ARCHITECTURE

- System Architecture
- TALENTICA SOFTWARE
- SAFEIN5 - PROPOSAL
- The proposed SafeIn5 system architecture is divided into 5 layers to support the Mobile first PULSE experience and scalable SIGNAL loop and Insights. Intelligence Layer supports the future AI needs.

| Layer | Components | Responsibilities |
| --- | --- | --- |
| Experience Layer | Mobile PWA (Community, Worker, Supervisor)Desktop Admin Console | Mobile-first experience for Community and Corporate users, supporting QR Scan, PULSE, Behaviour Signal Capture, Feed, Search, Learn 5, Rescue Plans and Supervisor Actions. Desktop-first administration experience supporting organisation setup, user management, QR configuration, content management, moderation and analytics. |
| Security & Access Layer | API Gateway, Authentication, Authorization, Identity Management, Roles, Tenancy, Audit Logging | Secure API access to platform services through authentication, role-based access control, tenant isolation, and audit logging to ensure data protection and governance. |
| Core Platform Services Layer | Behavioural Signal Service, Media Service, Classification Service, Search Service, QR Service, Workflow Service, Notification Service, Context Engine | REST services implementing core SafeIn5 capabilities including signal capture and lifecycle management, media processing, classification, search, QR context mapping, workflow execution and notifications. |
| Data & Media Layer | Operational Database, Media Storage, Audit Store | Stores behavioural signals, PULSE sessions, workflows, users, sites, assets, QR mappings, learning content, rescue plans, audit logs, photos, and videos with tenant isolation and row-level security. |
| Intelligence Layer | Event Outbox, Event Streams, Metrics Collection | Captures structured behavioural events, workflow events, context relationships, and usage metrics enabling future analytics, intelligence, and predictive insights. |

## Slide 18: SOLUTION DESIGN

- Design Principles
- TALENTICA SOFTWARE
- SAFEIN5 - PROPOSAL
- The following principles guide the design decisions to ensure alignment to SafeIn5 current and future requirements

| Requirement | How We Achieve It |
| --- | --- |
| Under 60-Second Capture | Single-screen capture experience, one-tap classification, background media uploads, and No mandatory inputs. |
| Voice & Media First Experience | Speech to Text, photo and video-first capture, minimal keyboard usage, large touch targets, and glove/goggle-friendly interactions. |
| Low Connectivity Resilience | Capture-first-sync-later, queued uploads, automatic retries |
| Anonymity | Anonymity is enforced at the data layer for MVP purposes and masked in audit logs. True anonymity will require masking of location, non-reversal by the admins etc. which is not considered as a part of MVP. |
| Context-Aware | QR-driven contextual routing, automatic attachment of site/sub-site/asset/task context, contextual PULSE and Rescue Plans |
| Corporate & Community models | Configurable workflows, multi-tenant architecture, role-based experiences |
| Flexible Learning Platform Integration | Adapter pattern to enable external integrations |
| Usage Metrics | Collect metrics such as active users, PULSE completion rates, SIGNAL Captures per user, Feed interactions, QR Scan frequency, and Anonymous usage to gain insights on Adoption. |
